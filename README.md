# Calculateur Pâtisserie

Petite app pour calculer le coût de revient et le prix de vente des pâtisseries : ingrédients, temps de travail, four, emballages, prix ami.

**Ouvrir l'app :** https://victorort-dev.github.io/calculateur-patisserie/

## L'installer sur l'iPhone
1. Ouvrir le lien dans **Safari**.
2. Bouton **Partager** (carré avec une flèche) → **Sur l'écran d'accueil** → **Ajouter**.
3. L'icône « Pâtisserie » apparaît sur l'écran d'accueil et s'ouvre en plein écran, même sans réseau.

## Où sont les données
Les recettes et les prix sont enregistrés **sur le téléphone**, dans l'app. Rien n'est envoyé sur internet.
Pense à faire de temps en temps **Réglages → Sauvegarder** et à garder le texte dans tes notes : il permet de tout restaurer sur un autre téléphone.
